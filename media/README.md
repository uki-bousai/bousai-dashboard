# 広報用の素材

SNS（リール／ストーリーズ）で使う動画と画像です。

| ファイル | 内容 | サイズ |
|---|---|---|
| `宇城市-在宅避難物資アプリ-リール.mp4` | アプリの説明リール（縦型・約43秒・音声なし） | 1080×1920 |
| `カバー写真.png` / `.jpg` | 上のリールのカバー（表紙）画像 | 1080×1920 |
| `ホーム画面に追加する方法-リール.mp4` | ホーム画面に追加する手順（iPhone・Android両方／縦型・約36秒・音声なし） | 1080×1920 |
| `カバー写真-ホーム画面.png` / `.jpg` | 上のリールのカバー（表紙）画像 | 1080×1920 |

## 使い方

- 動画は**音声なし**です。投稿アプリ側で好きな音楽を付けてください。
- カバー画像は、プロフィールの一覧で正方形に切り抜かれても伝わるよう、
  見出しを中央（上から420〜1500ピクセルの範囲）に置いています。
- 上下はSNSの操作ボタンで隠れるため、動画の文字も中央寄せにしています。

## 作り直すとき

画面写真は本番の公開ページ・入力画面をそのまま撮っています。
データや画面が変わったら撮り直しが必要です。

「ホーム画面に追加する方法」のスマホの画面は、写真ではなく説明用の図です。
アプリのアイコン（`icons/zaitaku-*.png` / `icons/nyuryoku-*.png`）を
差し替えたときは、この動画も作り直してください。
