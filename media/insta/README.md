# Instagram用の投稿画像

対策本部会議のまとめを、Instagramの連続投稿（カルーセル）にしたものです。

| | |
|---|---|
| サイズ | 1080×1350（4:5）。フィードでいちばん大きく出せる比率 |
| 枚数 | 表紙 → 各項目 → 案内 の順。ファイル名の番号どおりに並べてください |
| 投稿文 | 各フォルダの `投稿文.txt` をそのまま貼れます |

## 作り直しかた

`src/build.js` の `SLIDES` に、表紙・各カット・最後の案内を書きます。
本文は `seikatsu.json` の同じ日の `briefings` と内容を合わせてあります
（食い違うと混乱のもとになるため、ビルド時に同じ日付の報告があるかを確かめています）。

```
cd src && node build.js      # out/ に 1080x1350 のPNGが出ます
```

書き方のきまり:

- `**強調**` で太字になります
- 見出しや案内文の改行は、書いた位置でそのまま折り返します
- `note` は下端に置かれる補足。`warn: true` で注意（オレンジ）の見た目になります

## 気をつけていること

- 会議で報告されていないことは書かない。推測は載せない
- 制度の取り違え（応急修理制度と、上限56,400円の緊急修理）に必ず触れる
- 数字は日付とセットで書く（「8月16日時点で3,626件」など）
