# 炊き出しの告知（北山崎公民館）

| ファイル | 用途 |
|---|---|
| `炊き出し-掲示用A4.pdf` | 公民館・掲示板・回覧板用。A4 1枚（コンビニ印刷そのままでOK） |
| `炊き出し-掲示用A4.png` | 同じもののPNG（2480×3508 = A4 300dpi） |
| `炊き出し-SNS用.png` | LINE・スレッズ用の縦型（1080×1920） |
| `qr-map.png` | 地図の二次元コード単体 |

## 二次元コードの中身

`https://www.google.com/maps/search/?api=1&query=32.6460278,130.7470556`

北山崎公民館の位置（`zaitaku.json` と同じ座標）です。
読み取れることは確認済みですが、印刷後に一度スマホで試してください。

## 場所の案内図（`src/map-card.html`）

地図を主役にした版です。`src/` に `map.png`（Googleマップの画面写真）を置いて
`node src/build-map.js` を実行すると、その地図を貼った A4 とSNS用が出ます。
置かないと地図の枠だけになります。目印は `info.json` の `landmarks`（配列）へ。

※ この作業環境からは地図タイルを取得できない（通信が遮断されている）ため、
　 地図画像は人が用意して渡す必要があります。

## 日時などの入れ方

`info.json` の `when`（日時）、`menu`（内容）、`bring`（持ち物）、
`host`（問い合わせ）に文字を入れて `node build.js` を実行すると、
空欄が埋まった状態で作り直せます。空のままにすると手書き用の空欄になります。

作り直しに使うファイルは `src/` に入れてあります。
`src/build.js` は Playwright（Chromium）で描画して書き出します。
