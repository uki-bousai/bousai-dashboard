# 炊き出しの告知（北山崎公民館）

炊き出しの会場が **どこなのか** を伝えるための紙とSNS画像です。

| ファイル | 用途 |
|---|---|
| `場所の案内-掲示用A4.pdf` | **場所の案内（地図つき）**。公民館・掲示板・回覧板用のA4 1枚 |
| `場所の案内-掲示用A4.jpg` | 同じもののJPEG（2480×3508 = A4 300dpi） |
| `場所の案内-SNS用.png` | LINE・スレッズ用の縦型（1080×1920） |
| `炊き出し-掲示用A4.pdf` / `.png` | 日時などを書き込む用の告知（地図は二次元コードのみ） |
| `炊き出し-SNS用.png` | 同じもののSNS用 |
| `qr-map.png` | 地図の二次元コード単体 |

## 場所の伝え方

ひとつの手段に頼らず、4通りで伝えています。

1. **目印**（「セブン-イレブン 宇城豊野町山崎店」の北がわ など）── 地図が読めなくても近所で聞ける
2. **地図2枚**（まわりの様子／建物のちかく）── 遠くからと、着いてから
3. **二次元コード** ── スマホならこれで一発
4. **緯度経度** ── カーナビに直接入れる用

あわせて「南山崎公民館は使えません」を赤枠で明示しています。取り違えがいちばんの混乱のもとです。

## 二次元コードの中身

`https://maps.google.com/?q=32.6460278,130.7470556`

北山崎公民館の位置（`zaitaku.json` と同じ座標）です。印刷物で小さくなっても読めるよう、
短いURLにして格子を粗くしてあります。書き出したPNGから読み取れることは確認済みですが、
**印刷したあとに一度スマホで試してください**。

## 作り直しかた（`src/`）

地図画像は、Googleマップの画面写真を人が用意します
（この作業環境からは地図タイルを取得できないため）。

1. スマホでGoogleマップを開いて画面写真を撮る（広い範囲と、建物の近くの2枚）
2. 上下のアプリのボタンが写らないように切り取り、
   `src/map-wide-raw.png`（広い範囲）と `src/map-near-raw.png`（近く）として置く
3. `cd src && python3 annotate.py`
   … ピンの位置に「北山崎公民館」の見出しと方位を重ねて `map-wide.png` / `map-near.png` を作る
   （ピンの座標は `annotate.py` の `pin=` / `name_xy=` で調整する）
4. `node build-map.js` … A4とSNS用を書き出す

目印や日時は `src/info.json`（`landmarks` / `when` / `host` など）に入れます。
`src/build.js` を使うと、地図なしの「炊き出し-」版が作れます。
