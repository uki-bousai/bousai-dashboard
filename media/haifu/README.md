消えないようここに置いています。

| ファイル | 中身 |

## 個人名について

これらの資料に個人のお名前は入っていません（「担当議員さん」などの役割のみ）。

**議員ペアの仮案（議員名入り）は、この公開リポジトリには置いていません。**
議員名簿をもとにした割り当て表で、公開すべきものではないためです。
必要なときは別途お渡しします。

## 作り直しについて

2026年8月12日に作ったものです。そのあとアプリの画面が変わっているため、
資料の中の画面写真は現在の画面と少し違います（区カードの見た目、
品目のアイコン、更新日の表示など）。手順そのものは変わっていません。

作り直す場合は、元のHTMLから書き出します。日本語をPDFに埋め込むには
TrueType版のフォントが要ります（Chromium は OTF の日本語を Type3 で
書き出してしまい、字形が崩れることがあるため）。
